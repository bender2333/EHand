AgentProbe 是什么

不是另一个调试器，是 Agent 接管嵌入式闭环开发所必需的基础设施

🔲
Zynq-7020 SoM
FPGA + ARM 双核
硬实时采集 + 软件控制

硬件层：一块基于 Zynq-7020 的板卡，集成 SWD 调试/烧录、SPI Mock 引擎、8 通道信号分析器、UART 透传/嗅探。FPGA 做硬实时采集和协议解码，ARM 做事件聚合和 USB 通信。

软件层：一个 Python CLI 工具 ap，Agent 通过 --json 获得确定性的结构化输出——不是给人看的波形图，而是机器可消费的语义 JSON。

合约层：稳定的 Evidence Envelope、Terminal State、Topology Identity——Agent 不需要"理解"硬件，只需要消费标准化的验证结果。

核心闭环：Agent 自主验证

Agent 写代码 → 构建固件 → 烧录 DUT → 观测行为 → 诊断问题 → 修正代码 → 回归验证 → 输出报告
高亮部分 = AgentProbe 提供的物理能力
整个循环无需人类介入，直到 Agent 需要审批或遇到超出能力边界的问题

能力模块 vs 传统工具对照

能力 替代什么 Agent 怎么用 输出什么
SWD 调试/烧录 J-Link / ST-Link ap flash --target dut flash_result: {status, hash, verify}
8ch 信号分析 Saleae Logic ap capture --channels 8 --decode spi capture_result: {signals, events, decoded_frames}
SPI Mock 引擎 Bus Pirate / 手写桩 ap mock load --model spi_flash_nominal mock_result: {transactions, fidelity, violations}
UART 嗅探/透传 串口助手 / minicom ap uart snoop --baud 115200 uart_log: {timestamped_lines, markers}
诊断引擎 工程师经验判断 ap diagnose --json diagnosis: {terminal_state, bottleneck, confidence, next_action}

关键区别：传统工具输出波形图、hex dump、串口文本——需要人看懂。

AgentProbe 输出结构化 JSON：terminal_state、confidence、evidence、next_action。
Agent 不需要"看懂波形"，它消费的是语义化的验证结论。
