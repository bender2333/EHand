# AgentProbe SoM Baseboard

V1 uses a Zynq-7020 SoM or dev-kit path plus a minimal baseboard/topology that supports:

- Golden ↔ DUT SWD
- UART bridge/snoop
- SPI Mock/Analyzer
- 8-channel logic capture
- Shared ground and protected I/O routing
- Role-safe physical labeling for Golden, DUT, and external target connections
